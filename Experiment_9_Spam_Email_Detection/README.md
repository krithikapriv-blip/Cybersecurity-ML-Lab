# Experiment 9: Spam Email Detection using Naive Bayes

## Aim
To detect whether an email is Spam or Not Spam using the Naive Bayes machine learning algorithm.

## Algorithm
Multinomial Naive Bayes

## Libraries Used
- Scikit-learn

## Description
This program uses a sample email dataset to train a Naive Bayes classifier. It converts email text into numerical features using CountVectorizer and predicts whether a new email is Spam or Not Spam.

## Result
The model successfully predicts whether the given email is Spam or Not Spam
