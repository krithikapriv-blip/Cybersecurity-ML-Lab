# Experiment 11: Malicious Database Input Detection using Decision Tree

## Aim
To identify malicious database inputs using a Decision Tree machine learning algorithm.

## Algorithm
Decision Tree Classifier

## Libraries Used
- Pandas
- Scikit-learn

## Description
This program uses sample database input data containing special characters, SQL keywords, and input length. A Decision Tree classifier is trained to classify inputs as safe or malicious.

## Result
The program successfully classifies database inputs into Safe Input and Malicious Input categories.
