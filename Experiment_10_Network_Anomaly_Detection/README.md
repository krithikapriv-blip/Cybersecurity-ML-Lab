# Experiment 10: Network Anomaly Detection using K-Means

## Aim
To detect abnormal network traffic using the K-Means clustering algorithm.

## Algorithm
K-Means Clustering

## Libraries Used
- NumPy
- Scikit-learn

## Description
This program uses sample network traffic data containing traffic values. The K-Means algorithm groups the data into two clusters. The cluster with lower traffic values is considered normal traffic, while the other cluster is identified as anomalous traffic.

## Result
The program successfully groups network traffic into Normal Traffic and Anomaly categories using K-Means clustering.
